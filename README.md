# FCPXML to AAF: Mac app downloads (v0.5.0, test build)

Pick the one for your Mac (Apple menu ▸ About This Mac):

- **Apple Silicon** (M1, M2, M3, M4…): [Download FCPXML-to-AAF-v0.5.0-mac-apple-silicon.zip](https://github.com/smckays/fcpxmlaaf/raw/downloads/FCPXML-to-AAF-v0.5.0-mac-apple-silicon.zip) (33.9 MB)
- **Intel**: [Download FCPXML-to-AAF-v0.5.0-mac-intel.zip](https://github.com/smckays/fcpxmlaaf/raw/downloads/FCPXML-to-AAF-v0.5.0-mac-intel.zip) (35.7 MB)

## Install
1. Unzip, then drag **FCPXML to AAF** into Applications.
2. It's unsigned test software, so macOS blocks it the first time:
   - **macOS 15 or later:** open it, click Done, then System Settings ▸ Privacy & Security ▸ **Open Anyway**.
   - **macOS 14 or earlier:** right-click the app ▸ Open ▸ Open.
3. Click **Sample Project**, then **Export AAF**. The AAF lands on your Desktop.

After this version, updates install from inside the app: **Check for Updates** in the toolbar.

**READ ME FIRST.txt** inside the zip explains what to check in Pro Tools. Source code is on the [main branch](https://github.com/smckays/fcpxmlaaf).
