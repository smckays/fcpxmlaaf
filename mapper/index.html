Tester kit

Mac · about 0.5 MB

1 · Get the converter

Includes the converter, a sample project with test tones, and a READ ME.

2 · Run it

  1. Unzip, then double-click Convert to AAF.command. If macOS blocks it: right-click, Open.
  2. Pick the FCPXML (File → Export XML in Final Cut).
  3. Choose the preset from this page, or none.
  4. An AAF Export folder opens with the .aaf and a report.

For .mov/.mp4 audio, install ffmpeg: brew install ffmpeg

3 · Send back

  • In sync with picture at 3–4 spots?
